## 一、已经拍板的

### 1. 干劲（正面增益）

- **获得时机**：正常睡醒之后
- **效果**：移动速度 **+30%**
- **机制**：自定义 `MobEffect`，自带 `MOVEMENT_SPEED` 属性修饰符——和原版速度药水走同一条路，不是另写一套移动逻辑
- **时长**：3 分钟
- 待定：是否按「睡得沉不沉」分级、能否叠加/刷新、数值是否进 config

### 2. 困倦（负面增益）

- **触发**：该睡的时候没睡 → 下一次工作时间获得困倦
- **效果**：移动速度 **-15%**
- **主人特别强调的边界**：
  - 这里的「晚上」指**她自己的睡觉时段**，不是世界的夜晚
  - 女仆有白班 / 夜班之分，睡觉时间各不相同
  - 判定必须走**每只女仆自己的作息**，不能拿世界时间一刀切
- **「没睡」的判定（已定：甲 + 丙）**：
  - **甲**：她的睡觉时段里**根本没躺下过**（整段没有 `isSleeping`）
  - **丙**：躺下了但**睡眠时长不够**（阈值待定，暂按不足 2 游戏小时）
  - 不采用「乙（没睡着）」：被怪物打断属于受害者，不该再罚一次
- 待定：
  - 持续多久（一次工作时间？一个游戏日？）
  - 与干劲能否同时存在（互相抵消，还是按后到的覆盖）

### 2.1 增益图标需求（现有 / 待生成）

- 两个自定义效果各需要一张 **18×18** 效果图标（原版状态图标尺寸），透明底、1 像素深色描边、平涂
- 干劲：橙色系（握拳 + 火花）
- 困倦：蓝灰系（半闭的眼 + 泪滴）
- 生成后统一按「最近邻降到 18×18 + alpha 二值化」处理，和被子图标同一套流程

### 3. 睡觉回血

- **效果**：睡眠过程中每 **3 秒** 恢复 **1 点** 生命值
- 待定：
  - 是否只在自己的床 / 睡觉点生效
  - 午睡、赖床是否同享
  - 被打断是否清零
  - 是否允许超过自然恢复的上限

## 二、已记下、之后再细化

### 4. 被子的材质效果与解锁条件

- 方向：五种被面各给一条实际加成，把上次做的材质从「好看」变成「有用」
  - 羽绒被：入睡更快 / 回血更多
  - 棉被：抗打断（外面有动静也不容易醒）
  - 夏凉被：夏季不闷（免疫困倦）
  - 蚕丝被 / 化纤被：无加成
- 解锁条件：怎么拿到某种被面？初始全开 / 靠成就解锁 / 靠材料合成——之后再议

### 5. 成就系统

- 方向：首次盖被入睡、五种被面全体验、冬天连睡若干夜、一觉不被打断睡满 N 小时、赖床次数…
- 待讨论：走原版 `advancements`（数据驱动、界面现成）还是模组自绘页面

## 已实现（2026-11-08，待主人试玩后调数值）

- 注册 `sleep_well:vigor` 与 `sleep_well:drowsy`，移速走 `MOVEMENT_SPEED` 属性修饰符（MULTIPLY_TOTAL，+0.30 / −0.15），与原版速度叠加规则一致、属性面板可见
- 判定按每只女仆自己的 `getScheduleDetail() == Activity.REST`，白班夜班各自算；窗口内睡着累计 ≥ 1000 tick（1 游戏小时）才算「睡过」
- 起床时窗口内睡够 → 干劲（默认 180 秒）；窗口结束那一刻「没躺下过」或「窗口内睡不够」→ 困倦（默认 600 秒，暂定值）
- 睡着每 60 tick 回 1 点血，不超过上限
- 睡着时「困倦」每秒减少 10 秒剩余时长（含原版自然流逝，本模组只补差额）；任何睡眠都算——午夜正寝、白天补觉、赖床都消退，不看她当时是否在自己的作息窗口内
- 配置在 `effects` 段：`vigorEnabled` / `vigorSeconds` / `drowsyEnabled` / `drowsySeconds` / `drowsySleepDecayEnabled` / `drowsySleepDecaySeconds` / `sleepRegenEnabled`；移速百分比是代码常量
- 贴图 `textures/mob_effect/vigor.png`（46×46）、`drowsy.png`（222×239），原版图集按注册名取，不受 18×18 限制

## 三、技术锚点（现有可复用的东西）

| 需要的能力 | 现成的实现 | 说明 |
|---|---|---|
| 「她醒了」这一刻 | `sleep/SleepWakeDiagnostics` | 已能判定睡着→醒，并带打断原因、受伤、传送标记 |
| 「她的睡觉时段」 | `maid.getScheduleDetail() == Activity.REST` | 走每只女仆自己的日程，白班/夜班天然分开 |
| 每只女仆的开关 | `maid/MaidCapabilities` | lieIn、winterSkip 已经在这里，新开关照抄 |
| 季节判定 | `winter/SeasonBridge` | 静谧四季是否冬天 |
| 赖床/补觉状态机 | `liein/LieInHandler` | 午睡与夜睡的区别在这里 |

现状：**零 `MobEffect` 注册、零属性修饰符、零成就注册**，这三块都要新建。
